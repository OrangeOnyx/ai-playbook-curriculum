# 09 — Training

The training program. Onboarding, deep-dives, quarterly refresh, and advanced tracks.

## Files

- `onboarding-curriculum.md` — 5-module new-hire curriculum
- `department-deep-dives.md` — 3-hour biannual deep-dive template
- `quarterly-refresh.md` — 60-min quarterly all-hands refresh + certification tracks

## The learning ladder

1. **Onboarding (Week 1-3)** — pass the 5 modules
2. **Department deep-dive (biannual)** — 3 hours, mandatory
3. **Quarterly refresh (quarterly)** — 60 min, mandatory
4. **Certification tracks (optional)** — Prompt Engineer, Agent Builder, AI PM

## Ownership

- L&D owns delivery
- Steering Committee owns curriculum
- Department AI Champions own their department content
