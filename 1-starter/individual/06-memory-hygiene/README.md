# 06 — Memory Hygiene

Every major model now has memory. Curated memory is a superpower. Un-curated memory is drift.

## The rule

Memory should contain:
- Durable facts (name, role, projects, timezone)
- Persistent preferences (voice, formatting, length)
- Standing constraints (privacy line, banned topics)

Memory should NOT contain:
- Ephemeral tasks
- Personal secrets
- One-off preferences ("make this shorter")
- Anything that changes weekly

## Files in this folder

1. `what-to-tell-each-model.md` — the initial memory setup script for every provider
2. `memory-audit-template.md` — monthly review template

## Time budget

- Initial setup across all models: 30 minutes
- Monthly review: 10 minutes

## Definition of done

- Memory set consistently across ChatGPT, Claude, Perplexity, Gemini
- Monthly review scheduled
- Nothing sensitive stored in consumer memory
