# 05 — Model Routing

Which model to use when. The single biggest power-user skill after prompting.

## Files in this folder

1. `model-routing-cheat-sheet.md` — the one-page you print and keep near your monitor
2. `provider-strengths-matrix.md` — the deeper table with reasoning

## The principle

Every model has a shape. Use the right shape for the job.

- Long docs and careful reasoning → Claude
- Real-time facts and citations → Perplexity
- Ecosystem breadth and multimodal → ChatGPT
- Google Workspace and huge context → Gemini
- Cheapest good-enough → Groq (open-weight models)
- Real-time X data or spicy outputs → Grok

## Definition of done

- Cheat sheet printed or in a note app you check
- You've mentally sorted your top 5 daily tasks by which model handles each
