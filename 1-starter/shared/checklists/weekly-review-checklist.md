# Weekly Review Checklist

30 minutes, every Friday.

## Review
- [ ] Run the weekly-review prompt against your week's data
- [ ] Check API spending on each provider
- [ ] Scan the last week's memory additions (are any wrong / stale / private?)

## Prune
- [ ] Delete one unused prompt from your library
- [ ] Delete one stale memory entry
- [ ] Cancel or downgrade one unused subscription (if any)

## Add
- [ ] Add any new prompts from real usage this week
- [ ] Add any new jargon to your personal glossary
- [ ] Add any new model routing insights to your cheat sheet

## Verify
- [ ] Zero-retention still enabled on providers that support it
- [ ] No AI-generated content shipped without a human review pass
- [ ] Weekend automations paused if appropriate

## Reflect
- [ ] One thing to say no to next week
- [ ] Top 3 priorities for next week — write them down
- [ ] One model or feature to try next week
