# Daily Power-User Checklist

Not everything. Just the habits that compound.

## Morning (5 min)
- [ ] Open the daily brief automation output
- [ ] Note top 3 priorities on a sticky
- [ ] Quick scan: any AI release notes worth 5 minutes?

## Work-mode default posture
- [ ] Model routing cheat sheet visible or muscle-memory
- [ ] `.env.local` loaded, keys accessible
- [ ] Cursor / Claude Code / preferred IDE open
- [ ] Correct model selected for the current task (not just whatever tab was open)

## During the day
- [ ] Every time you write a prompt more than twice, save it to your library
- [ ] Every time a model hallucinates on a factual claim, note the source of the mistake
- [ ] Every time a term you don't know comes up, add it to your glossary
- [ ] Never paste anything crossing your privacy line

## Before EOD (5 min)
- [ ] Skim any incomplete drafts — should any go to inbox as drafts overnight?
- [ ] Note one thing that worked well with AI today, one that didn't
